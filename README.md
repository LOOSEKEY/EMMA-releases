# EMMA — downloads

**A private AI that lives on your computer, remembers you for life, and answers
only to you.** No cloud, no account, nothing phones home.

### → [ownemma.com](https://ownemma.com)

This repository exists only to host the installers. **There is no source code
here** — EMMA is closed source, and this is the public home for its downloads
and for the in-app update check.

## Download

Grab the latest build from **[Releases](../../releases)**:

| Platform | File |
|---|---|
| Windows | `EMMA-Setup-*.exe` |
| Linux (Debian/Ubuntu) | `emma_*_amd64.deb` — `sudo apt install ./emma_*.deb` |
| Linux (portable) | `EMMA-*.AppImage` — `chmod +x` and run |
| macOS | coming soon |

**You'll also need [Ollama](https://ollama.com)** — the local model engine EMMA
thinks with. It's a free, separate install, and EMMA's first-run setup links you
straight to the right one for your system and continues by itself once it's
running.

Every build is **unsigned**, so Windows shows *"Windows protected your PC"* on
first run — choose **More info → Run anyway**. A signing certificate is on the
list; until then we'd rather say so plainly than have it come as a surprise.
